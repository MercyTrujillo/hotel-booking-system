##Hotel Management Web Application

#Overview
Full-stack web application developed as an academic project to simulate a hotel management system. The platform allows users to browse rooms, make reservations, and simulate payments, while providing administrative functionality to manage bookings and monitor system activity. 
This project was developed as part of a university database course and focuses on demonstrating full-stack development fundamentals, database design, and basic system architecture.

#Features

#Customer Functionality
View available rooms
Make reservations
Simulated payment process
User registration and login

#Admin Functionality
View all reservations
Access reservation history
Manage system data and users


#Technologies Used

#Backend

PHP (custom MVC-like structure)
MySQL (database design and queries)

#Frontend

HTML
CSS
JavaScript
Bootstrap

#System Architecture

The application follows a structured separation of concerns:

modelo/: Data handling and database interaction
controlador/: Business logic and request handling
Views implemented using PHP and HTML for dynamic content rendering

#Database
Designed relational database using MySQL
Managed through MySQL Workbench
Includes tables for users, reservations, rooms, and transactions

#Key Learnings
Built a full-stack web application from scratch
Implemented user authentication and role-based access
Designed and connected a relational database
Applied MVC concepts without using a full framework
Developed both client-side and server-side functionality
